## 为什么之前统一不了

你做的 `style1.css`（30KB，米白 #FCFAF7 + 雾蓝 #87A8BC）一直只挂在 `index1.html` 上。

`result.html` 用的是 `css/style.css`——那是 11/11 最早的 4KB 骨架，冷蓝色系（#2b6cb0）、圆角 12px。所以封面和结果页完全是两套设计语言。

更麻烦的一层：结果页有三块内容是**脚本运行时自己往页面里插 `<style>` 的**，写死在 js 里，光改 css 压不住：

| 模块 | 文件 | 负责人 |
|---|---|---|
| 地图 + 方案切换页签 + 图例 | `js/map-view.js` | 张宇桐 |
| 三方案对比表 | `js/compare-table.js` | 闫雅欣 |
| 数据可信度提示条 | `js/data-hint.js` | 张海燕 |

这三个文件都不要动（动了会跟她俩的改动打架）。正确做法是在 `result.css` 里覆盖。

## 你要做的

打开 `css/result.css`，里面已经把三组模块的类名全列好了，照着写就行。

### 一、方案卡片（最显眼，建议先改）

```css
.scheme-card            /* 卡片本体，含 .best 推荐态 */
.scheme-score           /* 右上角综合得分 */
.scheme-rank            /* ★推荐 / 备选 标签 */
.conclusion             /* 三句话结论 */
.metrics .metric        /* 四个指标格子 */
.metric b / .metric span/* 数字 + 标签 */
.leg                    /* 每个人的路线行 */
.bottleneck-tag         /* 瓶颈成员标签 */
.page .header           /* 页面容器 + 标题区 */
```

这块现在还是冷蓝 + 绿边（`.best` 是 `#f0fff4` 浅绿底 + `#2f855a` 绿边），跟你的橘色 #E69F66 不搭。

### 二、对比表（闫雅欣的模块，只覆盖不改文件）

```css
.jbx-ct-wrap  .jbx-ct-title  .jbx-ct-note
.jbx-ct-head  .jbx-ct-min  .jbx-ct-unit
.jbx-ct-badge  .jbx-ct-rank  .is-best  .jbx-ct-empty
```

⚠️ 这个模块里有 2 处 `!important`，如果你的规则压不住，就在你的规则后面也加 `!important`。

### 三、地图区（张宇桐的模块）

```css
#mapBox  #mapTabs  #mapArea  #mapHint
.jbx-tab              /* 三方案切换页签 */
.jbx-legend           /* 图例 */
.jbx-mk .jbx-mk-dot   /* 地图上的标记点 */
.jbx-map-note         /* 提示文字 */
```

地图里那几种线的颜色是写死的（地铁 #3182ce / 打车 #dd6b20 / 骑行 #38a169），**线本身在地图画布上，CSS 改不了**，只能改外面的图例和页签。如果图例颜色和线不一致会很怪，所以图例文字配色你可以改，那几个色块的颜色**必须保留**。

### 四、数据提示条（我的模块）

```css
.data-hint  .data-hint__icon
.data-hint--ok    /* 全真实·绿 */
.data-hint--warn  /* 部分估算·黄 */
.data-hint--bad   /* 全估算·红 */
```

这条是答辩加分项——它会在数据降级时如实告诉用户"这是估算"。**状态色建议保留绿/黄/红的语义**，但底色调成你的沙色系没问题。

## 三条红线

1. **不要改 class 名和 id 名**。三个 js 全靠这些名字找节点，改一个页面直接空白。
2. **不要在原文件里改**。`style.css`、`style1.css`、三个 js 都别动，全部写进 `result.css`。谁的文件谁负责，写进去以后冲突了很难查。
3. **不要用 `display:none` 藏 `#schemeList` / `#compareTable` / `#mapArea`**。对比表内部靠"schemeList 是否存在"判断要不要渲染，藏了会连带整块消失。

## 顺带两件小事（在你自己的 `index1.html` 范围内）

1. 建房表单我加了「出行城市」下拉（`<select id="cityInput">`），引擎没城市没法解析地名，删不得。iOS 上 `<select>` 和 `<input>` 高度对不齐，需要你补个样式。
2. 房间页「汇合方式」三选一现在是死的——引擎一次算三套，结果页并排对比自动打分，不需要用户提前选。建议删掉，或者改成"你最看重什么（最省钱/最省时/最少等待）"，后者我能接上引擎的权重。
