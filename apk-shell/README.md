1. HBuilderX 打开本目录 → 若有提示「重新获取 appid」点一下（本项目 appid 已生成：`H5880E285`）

3. 打包方式选 **使用自有证书**（不是公共测试证书）

## 地图选点灰屏修复（11-17）

真机测试发现 iPhone Safari / 安卓微信里地图选点弹层瓦片全灰（logo 和地址正常、只有瓦片不画）。
根因：弹层 `height:64vh` + 入场动画期间，地图容器的 `flex:1` 实际高度算出为 0，
高德 2.0 在 0×0 容器里初始化后瓦片永不重绘。

`map-picker-FIXED.js` 的修复：建图前关动画 + 双 rAF 等布局落定 + 给容器写死实测像素宽高 +
建图后 50/250/600/1200ms 多次 `resize()` 兜底。部署时用它替换 `js/map-picker.js`。
